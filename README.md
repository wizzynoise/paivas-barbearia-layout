# Paiva's Barber — website layout concept
Website layout concept for a barbershop in César, Oliveira de Azeméis, Portugal.

**Status: Demo / layout concept — not delivered.** This is not the barbershop's official website.

Site content is in European Portuguese.

## Stack
React 18 · TypeScript · Tailwind CSS · Vite · React Router

## Run locally
```bash
npm install
npm run dev
npm run build
```

## Structure
- `src/components` – reusable components
- `src/pages` – pages
- `src/assets` – images
- `public` – static files
